🧠 사상가 모델 업데이트

Simon Willison

바뀐 점 · 프롬프트 엔지니어링 관점 전환: few-shot 예시와 부정지시가 신모델에서 품질을 '저하'시킨다고 방향을 뒤집음. 또한 사이버 위협 인식이 prompt injection 완화 가능 수준에서 '모델이 자율적으로 취약점을 체이닝해 실제 exploit을 만든다'로 격상.

일관된 것 · 공격 벡터를 사전 차단하고 exfiltration 채널을 제약하는 실용적 방어 철학, coding agent를 저마찰 툴 제작에 활용하는 습관은 유지.

새 아이디어 · 가드레일이 방어자(commercial API 필터에 막힘)와 공격자(open-weight로 무제약) 사이에 위험한 비대칭을 만든다는 통찰. Opus 5의 가장 흥미로운 점은 벤치마크가 아니라 prompt injection 저항성이라 평가.

Better Models: Worse Tools

Boris Cherny

바뀐 점 · 수동 plan 중심에서 auto mode·self-verification loop 기반 자율 워크플로우로 이동. Opus를 몇 시간~며칠 자율 실행하는 것이 실무적으로 viable하다고 봄.

🧪 기회 — 무엇을 만들까

  • Claude Code CLAUDE.md의 부정지시·few-shot을 제거한 positive-only 버전을 A/B해 instruction-adherence를 정량화하는 사내 실험 프레임워크 구축
  • depth-3 nested subagent(planner→implementer+verifier) 오케스트레이션을 concurrency/budget cap과 함께 실전 리팩터로 스트레스 테스트
  • human review 트리거 없이 test-green까지 자율 root-cause 디버깅하는 self-verification loop를 만들고, '언제 멈췄어야 하는가'를 로깅해 자율성 경계 정립
  • 프로덕션 agent trace 이슈 탐지용 저비용 post-trained 판별 모델(예: fine-tuned judge) 도입으로 online eval·tokenomics 가시성 확보
  • LLM 기반 개인 knowledge base(auto index/summary + wiki 누적) 워크플로우로 RAG 없이 소규모 retrieval 파이프라인 구축
