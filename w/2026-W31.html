🧪 기회 — 무엇을 만들까

  • 기존 Claude Code system prompt를 few-shot·부정지시 제거 버전과 A/B 비교하는 사내 실험 파이프라인 구축(동일 10개 태스크로 품질·adherence 스코어링)
  • human 승인 체크포인트 없이 write→test→root-cause→반복하는 self-verifying 코딩 에이전트 루프를 만들어 stop-at-first-attempt 대비 완료율 측정
  • nested subagent(depth 2-3) 오케스트레이션으로 멀티파일 refactor를 수행하고 concurrency/budget cap의 효과 검증
  • 소규모 개인 지식베이스(자동 index/summary 파일)로 fancy RAG 없이 retrieval 품질을 확보하는 agent-built wiki
  • 에이전트 token spend를 조기 탐지·상한 설정하는 tokenomics 가드레일과 online/offline eval 결합 관측 스택
