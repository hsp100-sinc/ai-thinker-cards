🧪 기회 — 무엇을 만들까

  • Claude Code system prompt A/B 하네스: few-shot+negative list(A) vs 최소 positive prompt(B)를 10개 동일 task로 pass rate·rework loop 비교 — belief shift 직접 검증
  • self-verifying 워크플로우: failing test suite를 주고 human review 없이 root-cause→fix→loop까지 자율 실행, 완료율과 '멈췄어야 할 지점' 로깅
  • depth-3 nested subagent orchestrator(orchestrator→planner→implementer+verifier, concurrency cap) 구축 후 flat agent 대비 토큰 비용·성공률 측정
  • 방어자용 cyber payload 분석 도구: commercial 필터에 막히지 않는 안전한 분석 경로 설계(guardrail 비대칭 완화)
  • agent 간 학습 공유('Stack Overflow for coding agents')와 portable agent skill(.md skills) 패키징
  • online eval + LLM-as-judge / fine-tuned 소형 judge로 production agent trace를 저비용·고정확 모니터링하는 파이프라인

⚠️ 리스크 — 무엇을 경계할까

  • 다수 top signal이 2026-dated 가상/미래 서술(GPT-5.6, Fable, Opus 4.6 등 fabricated model 포함) — 사실로 인용하지 말고 '방향성 신호'로만 취급

  • benchmark gaming과 종합 지표 맹신: ECI 등 aggregate index가 real-world agentic 성능을 과대/과소 평가할 수 있음
  • LLM의 단방향 설득력·sycophancy — 그럴듯하지만 진위와 무관한 논증을 경계, 반대 입장 논증을 요구
