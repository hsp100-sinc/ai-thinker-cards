🧪 기회 — 무엇을 만들까

  • self-verifying Claude Code loop 제품/템플릿: 실패 test suite를 주고 root-cause 디버깅→scratch 검증 스크립트 작성→전부 통과까지 무중단 iterate, iteration 수와 self-tooling 여부를 로깅
  • prompt 스타일 A/B 하네스: (A) few-shot+긴 negative list vs (B) 간결 positive-only를 고정 코딩 태스크에 각 5회 실행해 품질/일관성 스코어링 — belief shift 직접 검증
  • nested subagent orchestration 벤치: orchestrator+planner/implementer/reviewer 구조를 single-agent와 token·wall-clock 비교, hard cap(~200) 발동 지점 관찰
  • MCP 서버(filesystem+내부 API tool) + Claude Code로 30+ step multi-turn tool 태스크에서 tool-call loop·context bloat 파괴 지점 측정
  • agent 지출·trace observability 계층: coding agent의 주당 비용 폭발과 trace 이슈를 저비용 post-trained 모델로 탐지·경보하는 운영 도구

⚠️ 리스크 — 무엇을 경계할까

  • top_signals와 belief_shift 상당수가 2026 미래시점·speculative/fictional 프레이밍(GPT-5.6, Fable 5, Claude Mythos 등 가공 모델명 포함) — 사실로 인용하지 말고 '방향성 신호'로만 취급
