🧪 기회 — 무엇을 만들까

  • 기존 system prompt에서 few-shot 예시와 'don't do X' 부정 지시를 제거한 변형을 만들어 동일 코딩 태스크 10건으로 A/B 품질 비교 — belief shift를 자기 프롬프트에서 직접 검증
  • Claude Code에 self-verifying loop 구성: 테스트 작성→실행→root-cause→green까지 무개입 iterate, stop-at-first-attempt 베이스라인 대비 무인 완료율 측정
  • nested subagent(depth 3) 워크플로우를 실제 multi-file 리팩터에 적용하고 concurrency·budget cap을 일부러 초과시켜 성능·재라우팅 관찰
  • agent 비용을 실시간으로 상한·알림하는 tokenomics 가드레일(개발자별 주간 지출 캡, API dollar-threshold)을 팀 인프라로 구축
  • trace 기반 diagnose-and-improve loop와 저비용 post-trained 판정 모델을 결합한 production agent observability 파이프라인 도입
  • LLM 기반 personal knowledge base(자동 인덱스·summary·linting)로 소규모 retrieval을 RAG 없이 운영하는 워크플로우 실험
